# Zen Mobile releases

Signed APKs of Zen Mobile, an unofficial Android browser that shows your Zen Browser Spaces through Firefox Sync.
Zen Mobile checks this repository once a day and installs new versions by itself.

To install it the first time, download the newest `zen-mobile-*.apk` under [Releases](../../releases) on your phone and open it.

Zen Mobile is not affiliated with or endorsed by the Zen Browser project or Mozilla.
